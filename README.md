# Beacon One Capital – Responsive Real Estate Landing Page

A modern, responsive **real estate investment landing page** built with HTML5, CSS3, Bootstrap 5, and JavaScript. The project presents Beacon One Capital with a clean corporate layout focused on property transformation, commercial real estate, and community development.

## 🌐 Project Overview

This project is a frontend implementation of a real-estate-focused landing page. It combines Bootstrap's responsive grid and components with custom CSS styling to create a polished desktop, tablet, and mobile experience.

The page includes:

- Responsive navigation bar
- Hero/banner section
- Property-focused content sections
- Property image/card grid
- Testimonials carousel
- Call-to-action contact section
- Newsletter area
- Social media icons
- Responsive footer

## 🚀 Getting Started

No backend or database is required to run this project.

### 1. Clone the repository

```bash
git clone https://github.com/your-username/beacon-one-capital.git
```

### 2. Open the project

```bash
cd beacon-one-capital
```

### 3. Run the website

Open `index.html` directly in your browser, or use **Live Server** in Visual Studio Code.

Recommended:

```text
Right click index.html → Open with Live Server
```

The **Arvo** typeface is used as the primary project font.

## ⚠️ Current Limitations

This is currently a **frontend UI project**, not a complete production real-estate platform.

Some elements are currently placeholders/demo functionality:

- Navigation links use `#`
- Contact buttons do not submit a real contact form
- Newsletter input is not connected to a backend
- Social media links are placeholders
- Property card content contains placeholder text in some cards
- Testimonials use demo content/profile images
- There is no database or backend API
- There is no authentication or CMS
